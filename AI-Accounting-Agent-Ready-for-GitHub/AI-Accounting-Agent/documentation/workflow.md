# Workflow

1. Collect source files and opening balances/COA.
2. Use synthetic or anonymised files for testing.
3. Attach files to Claude and run the master prompt.
4. Review extraction coverage, duplicate flags and classification.
5. Approve or amend proposed journal entries.
6. Review GL, Trial Balance and financial statements.
7. Resolve exceptions and reconcile accounts.
8. Export final workbook and store it in a restricted location, not public GitHub.
9. Preserve approved versions and source records securely.

This project provides draft accounting outputs; a responsible accountant must review before posting or filing.
