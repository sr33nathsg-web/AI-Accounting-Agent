# Accounting Rules and Control Principles

- Double-entry: each journal must balance.
- Source traceability: journal entries link to transaction IDs and source locations.
- No unsupported entries: estimates or assumptions must be clearly labelled.
- No forced Trial Balance: investigate errors rather than using an unexplained plug.
- Bank movements alone do not establish accrual revenue or expense.
- Opening balances are required for complete Balance Sheet and cumulative ledger outputs.
- Reconciliation is distinct from classification.
- Financial statement mapping must be consistent.
- GST and tax treatments require evidence and professional review.
- Review proposed entries, adjustments, exceptions and control results before finalisation.
