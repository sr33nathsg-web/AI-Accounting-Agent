# Upload to GitHub

## Browser upload
1. Create a repository on GitHub. Consider setting it to Private.
2. Extract the ZIP locally.
3. Open the repository page.
4. Choose Add file → Upload files.
5. Drag the extracted project contents into the upload area.
6. Commit the changes.

## GitHub Desktop
1. Create or clone a repository.
2. Copy this folder's contents into the local repository.
3. Commit and push.

## Security
Never upload actual bank statements, customer/vendor details, payroll data, IDs, account numbers, passwords, API keys or other confidential records. The included example is synthetic. Keep real accounting workbooks outside the repository.
