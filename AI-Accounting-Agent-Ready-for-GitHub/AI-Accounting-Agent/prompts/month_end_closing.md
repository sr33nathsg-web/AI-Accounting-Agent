# Monthly Close Checklist – AI Accounting Agent

## Data and posting
- [ ] Gather statements, invoices, receipts, payroll and supporting files.
- [ ] Confirm reporting period and completeness.
- [ ] Check transaction duplicates and missing data.
- [ ] Classify and draft journals.
- [ ] Review and approve uncertain entries.

## Reconciliation
- [ ] Reconcile each bank account.
- [ ] Reconcile receivables and payables if reports are supplied.
- [ ] Review loans and director accounts.
- [ ] Review GST control accounts where applicable.
- [ ] Review payroll, CPF and levy balances where applicable.

## Adjustments
- [ ] Accruals and prepayments.
- [ ] Depreciation based on asset register and policy.
- [ ] Inventory and cost-of-sales adjustments where supported.
- [ ] FX adjustments where applicable and supported.
- [ ] Tax provision only with appropriate support.

## Reporting and controls
- [ ] Trial Balance balances.
- [ ] P&L reviewed.
- [ ] Balance Sheet reconciles.
- [ ] Cash flow prepared where possible.
- [ ] Exceptions and suspense reviewed.
- [ ] Period comparison prepared if prior periods available.
- [ ] Workbook archived securely outside public repositories.
