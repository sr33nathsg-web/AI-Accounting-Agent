# Transaction Classification Rules

Use this as a companion reference to the master prompt.

1. Bank receipts are not automatically revenue; check receivables, advances, refunds, loans, capital and transfers.
2. Bank payments are not automatically expenses; check payables, assets, loan principal, deposits, prepayments and transfers.
3. Transfers between accounts owned by the same entity should be paired and excluded from income/expense.
4. Principal and interest components of debt payments must be separated if evidence exists.
5. Capital purchases require assessment against the company's accounting policy; do not invent a capitalization threshold.
6. Refunds should reverse or adjust the original account where identifiable.
7. Director/shareholder transactions require evidence and may be loans, remuneration, reimbursements or equity.
8. GST should be separated only when the tax status and documentation support it; flag uncertain treatment.
9. Foreign currency transactions: retain original currency and amount, exchange rate source/date and translated amount when supplied. Do not invent FX rates.
10. Unknown entries should be placed in a review queue, not automatically in miscellaneous expense.
11. Document all assumptions and confidence levels.
12. Each journal line should be linked to a source ID.
